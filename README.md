# VLADYERIK ARCADE

Portal independiente para el futuro gabinete arcade y acceso online a juegos VLADYERIK.

## Publicación
Configurar GitHub Pages en **Settings → Pages → Deploy from a branch → main / (root)**. La URL esperada es https://gastongonz82.github.io/vladyerik-arcade/ (confirmar publicación antes de compartir como operativa).

## Estado
- Portada online independiente implementada.
- Enlaces a categorías de vladyerik.com.
- El prototipo de navegación por gamepad sigue en la rama feature/vladyerik-arcade-cabinet del repositorio gastongonz82/juegos.
- Los juegos alojados en otro origen NO pueden recibir eventos sintéticos del joystick desde esta página por la política de mismo origen del navegador.
- Para jugar desde la máquina con mando habrá que alojar copias de juegos autorizadas aquí o integrar controles nativos en cada juego. No se afirma compatibilidad de mandos todavía.

No modificar vladyerik.com ni la rama main de gastongonz82/juegos como parte de estas pruebas.
